# S05_Phase4_Position (环节四：定位 - 折叠的空间)

> **Context**: 45:00 - 55:00
> **Ref**: [SLIDE: S14_Visual_Inception]

**(镜头：林昕老师将双手在胸前合拢，然后猛地向两边展开)**

最后一步，也是最容易被忽视的一步：**定位 (Position)**。

**(PPT: 切换至 S14_Visual_Inception [REF: S14_Visual_Inception])**

还记得《盗梦空间》里那个折叠的巴黎吗？
在普通的单声道（Mono）里，所有的声音都挤在中间，那是一条线。
在普通的立体声（Stereo）里，声音是一个平面。
但我们想要的是一种**包裹感**，一种**眩晕感**。我们要把这个平面不仅拉宽，甚至要把它“折叠”过来，包住你的脑袋。

**(Deep Listening: 寻找脑后的声音)**

这一步，请大家务必**戴上耳机**。
我们来做一个“指认实验”。闭上眼睛，伸出你的食指。
等一下声音响起来的时候，请你用手指去指——声音到底是从哪里发出来的？

**(留白 40秒)**
... (声音在变化) ...
你的手指是不是在移动？
一开始，它指着你的眉心（单声道）。
然后，它移到了你的左右耳（立体声）。
最后... 你的手指是不是不自觉地想要指向你的后脑勺？

这就对了。那种让你觉得“声音跑到了脑后”的迷幻感，就是我们今天要追求的极致声场。

我们用到的是书上 6.9.3 章节：**立体声扩展器 (Stereo Expander)**。

**(操作: 效果 -> 立体声声像 -> 立体声扩展器 [ACTION: ACT_07_Stereo_Expand])**

我们的导演决策在这里非常关键：
*   **如果不动 (0% - 100%)**：爱丽丝只是在一个普通的洞里。
*   **如果收窄 (Narrow)**：这种压迫感，像是在一个狭窄的棺材里。
*   **如果扩展 (Wide)**：这种失重感，才是我们要的“奇幻坠落”。

**(操作: 调节扩展参数)**
我要做一个疯狂的决定。我要把扩展量推到 **150%** 甚至 **200%**。

**【警告】相位抵消 (Phase Cancellation)**
书上 6.9.3 严肃警告过我们：*“过度扩展会导致相位抵消。”*

**(可视化演示: 波形抵消)**
大家看这个图。左声道的波形是向上的（波峰），右声道的波形是向下的（波谷）。
如果在立体声耳机里听，没问题，很震撼。
但是，如果这两个信号合到一起（Mono），+1 加上 -1 等于什么？
等于 0。
这意味着，那些珍贵的低频和人声，可能会因为你的“贪心”而被物理消除。

**(示范: 手机单声道灾难现场)**
我切换到 **单声道 (Mono)** 模拟手机外放。
*(播放音频)*
听到了吗？声音突然变得很空、很薄，就像中间被掏空了一样。这就是 **“中空” (Hollow)** 现象。

但在今天这个“艺术作品”里，我们要的就是这种边缘试探的迷幻感。我们要让声音听起来不像是从两个喇叭里出来的，而是直接在你的**两侧太阳穴**响起的。

**(操作: 播放试听)**
再听一次。
*(播放音频)*
你不再是通过屏幕看爱丽丝，你是**变成了爱丽丝**，你被包裹在这个声音的漩涡里。

这就是声音导演的终极魔法——我们不仅控制声音的内容，我们还控制**听众在声场中的位置**。

好了，四个步骤全部完成。
从**净化**（黑客帝国的白屋），到**塑形**（巨人的变形），再到**置景**（无底深渊的混响），最后**定位**（盗梦空间的折叠）。
我们把一段平平无奇的读书声，变成了一场奇幻的坠落之旅。
