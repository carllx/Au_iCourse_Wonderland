# S03_Phase2_Sculpt (环节二：塑形 - 改变身份的药水)

> **Context**: 15:00 - 30:00
> **Ref**: [SLIDE: S08_Visual_Alice_Drink]

**(镜头：林昕老师手里拿出一张爱丽丝的剪影卡片，把它捏弯了)**

如果是画画，改变一个人的样子很简单，擦掉重画就行。
但在声音的世界里，我们不能重画。我们只能——**整容**。

**(PPT: 切换至 S08_Visual_Alice_Drink [REF: S08_Visual_Alice_Drink])**

大家记得书里爱丽丝喝下那瓶药水后发生了什么吗？她忽而变大像巨人，忽而变小像老鼠。
作为声音导演，现在我们要决定主角的“物理形态”。
**导演提问**：*此刻的爱丽丝，是那个吓得瑟瑟发抖的小女孩，还是那个足以踩碎扑克牌士兵的巨人？*

为了营造那种“掉进深渊”的无助感，我们的决定是：**让她变小**。
变小意味着什么？意味着周围的世界变大了，巨人的声音会对她造成压迫感。或者反过来，我们让她的声音变得尖细，像个闯入巨人国的小精灵。

这就需要用到本书 6.10 章节的重型武器：**变调器 (Pitch Shifter)**。

**(操作: 效果 -> 时间与变调 -> 变调器 [ACTION: ACT_04_Pitch_Shift])**

打开面板。这里有两个核心概念，很多人学完了还会搞混：
1.  **音高 (Pitch)**：决定了你是男高音还是男低音。
2.  **音色 (Timbre)**：决定了你是人类还是外星人。

我们先来做“变调”。这也是最容易翻车的地方。
很多同学以为变调就是拉个滑块，结果调出来像什么？像**绑匪电话**。那种空心的、甚至带着金属味的声音，我们叫它 **“隧道效应” (Tunnel Effect)**。

怎么避免？看这两个参数。

第一，**半音阶 (Semitones)**。
我们要把她变小，就要提高音调。试着设为 **+3**。这就相当于把橡皮筋拉紧了。

第二，**【关键技术点】拼接频率 (Splicing Frequency)**。
这是书上 6.10.4 的重点。简单说，变调就是把声音剪碎了重新拼。这个频率就是你剪刀的速度。
*   剪得太快（高频）：切片太碎，声音虽然连贯但没有厚度，就会出现隧道音。
*   剪得太慢（低频）：切片太大，会有明显的卡顿。
*   **默认值**：通常是最好的选择。

**(Deep Listening: 辨别身份的重量)**

现在，我要大家闭上眼睛。
我会播放两段变调后的声音。一段是 **+3 Semitones**，一段是 **+5 Semitones**。
请不要关注它有多尖，而是去感受：**哪一个更像是一个有血有肉的“人”，哪一个像是一个失去重力的“卡通角色”？**

**(留白 30秒)**
...
...

大家听出来了吗？
**+5** 的那个，虽然更“小”，但它飘了。它失去了作为人的“重量感”，变成了米老鼠。
而 **+3**，虽然变化不大，但它保留了“人”的质感。我们是在拍电影，不是在拍动画片。所以，作为导演，以此为界，我们选择 **+3**。

但这就够了吗？
不够。爱丽丝变小了，但她的喉咙结构还没变。我们还需要做一项更精细的手术：**改变共振峰 (Formant)**。

**(补充操作: 6.8 人声增强 [ACTION: ACT_03_Vocal_Enhancer])**
我们叠加一个 6.8 章节的 **人声增强 (Vocal Enhancer)**。
这里有一个神奇的开关。虽然我们的原声可能是女声，但我建议大家试一下切换到 **"Music"** 模式，或者手动调节频率。
我们不仅仅是改变音高，更是要改变她口腔共鸣的大小。

**(操作: 应用效果)**

现在，我们的主角“塑形”完成了。
她不仅仅是变了调，她有了一个全新的、脆弱的物理形态。
接下来，我们要把这个脆弱的小人，扔进一个巨大的空间里。
