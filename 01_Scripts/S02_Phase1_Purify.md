# S02_Phase1_Purify (环节一：净化 - 移除现实的尘埃)

> **Context**: 05:00 - 15:00
> **Ref**: [SLIDE: S05_Visual_Matrix]

**(镜头：林昕老师切换到操作界面，眼神专注)**

好，我们要开始造梦了。但首先，我们要学会“清理”。

**(PPT: 切换至 S05_Visual_Matrix [REF: S05_Visual_Matrix])**

大家看过《黑客帝国》吗？尼奥第一次进入 Matrix 的系统时，是在一个纯白色的空间里。那里什么都没有，只有他和墨菲斯。为什么？因为只有在一个绝对纯净的背景上，你才能构建出任何你想要的世界。

我们现在的音频，充满了现实世界的“尘埃”——就是这个嘶嘶的底噪 (Hiss)。如果保留它，听众就永远被困在录音的那间屋子里，出不来。
所以，作为导演，我们要做的第一个决定是：**我们要现实的尘埃，还是要梦境的纯洁？**
今天的剧本是《爱丽丝漫游奇境》，是一个非现实的梦。所以我的决定是：**我们要绝对的纯净，比常规还要更狠一点。**

*(教师备注：此处使用 Plan A 录音素材。若使用 Plan B TTS 干声，可直接演示“如何添加底噪再消除”，或假装处理以配合教学)*

**(操作: 打开 Audition，选中包含底噪的静默片段)**

我们使用的是 **"降噪/恢复 > 降噪(处理)"**，对应书上的 6.6.2。
这个工具非常聪明，但它需要你教它：**“什么是噪声？”**

第一步，**捕捉嫌疑犯 (Capture Noise Print)**。
我们要选中一段只有噪声、没有人声的空白区域。这就是告诉 Audition：“看好了，这种长相的声音，统统给我抓起来。”
**(操作: 选中噪音频段 -> 效果 -> 降噪/恢复 -> 捕捉噪声样本 [ACTION: ACT_01_Capture_Print])**
快捷键 Shift+P。记住这个快捷键，它是你以后最常用的清扫工具。

第二步，**全城搜捕 (Noise Reduction Process)**。
现在我们取消选取，选中整段音频。告诉它：去吧，把全城里长这样的家伙都清理掉。
**(操作: Ctrl/Cmd+A 全选 -> 效果 -> 降噪/恢复 -> 降噪(处理) [ACTION: ACT_02_Reduce_Noise])**

**(界面: 弹出降噪参数面板)**

看这个面板。这里有几个核心参数，我们不仅要看上面的滑块，还要点开 **【高级】(Advanced)**。

1.  **降噪幅度 (Noise Reduction)**：通常 50%-70% 比较自然。但为了“真空”感，我推至 **90%**。

2.  **降噪量 (Reduce by)**：决定压低多少分贝。

3.  **【关键技术点】频谱衰减率 (Spectral Decay Rate)**：
    这是书上 6.6.2 重点提到的参数。它决定了被判定为噪音的声音“死得有多快”。
    *   如果设得太低（小于 40%），声音消逝太快，会留下咕噜咕噜的 **“气泡声” (Bubbles)**，就像水开了一样，这是最典型的人为痕迹。
    *   我们把它稳在 **65%** 左右。既要杀敌，又不能留下尸体。

4.  **【关键技术点】平滑 (Smoothing)**：
    为了进一步消除那种“数码味”的毛刺，我们将平滑值提高到 **1** 或 **2**。这会牺牲一点点声音的细节锐度，但能让背景听起来像丝绸一样顺滑，而不是粗糙的砂纸。

**(操作: 调节参数，并在“仅输出噪声”上打钩预览)**
这里有个小技巧，勾选这个 **"Output Noise Only" (仅输出噪声)**。
这时候你听到的，应该是纯粹的“嘶嘶”声。仔细听那嘶嘶声里有没有混入人声的“窃窃私语”。如果有，说明我们的手术刀切到了血管。但在“平滑”参数的保护下，这种风险应该被降到了最低。

但今天，为了追求那个Matrix般的纯白空间，我愿意牺牲一点点人声的质感。

**(操作: 取消勾选，点击应用)**

好，听一下。
**(操作: 播放处理后的音频)**
世界安静了。这种突如其来的寂静，是不是本身就有一种... 不太真实的压迫感？对，这就是我们要的。

现在，白纸铺好了。我们要让爱丽丝登场了。
