## 📊 音频技术参数

新生成的音频包含：

### 心跳信号 (Signal)
- **基频**: 60 Hz
- **谐波**: 120 Hz, 180 Hz, 240 Hz
- **BPM**: 50
- **能量**: +3dB (1.4)
- **特征**: 自然的"咚咚"声，有丰富的谐波结构

### 噪音信号 (Noise)
- **类型**: 粉红噪音 (Pink Noise)
- **频谱**: 宽带 (覆盖整个频谱)
- **能量**: -6dB (0.5)
- **特征**: 自然的背景"嘶嘶"声

### 混合比例
- **心跳 : 噪音** = 1.4 : 0.5 ≈ **3 : 1**
- **频谱特征**: 自然混合，低频心跳主导，中高频噪音覆盖

## ✅ 正确的操作步骤

### 第 1 步：打开音频文件
1. 在 Audition 中打开 `asset_S02_dirty_heartbeat.wav`
2. 确保在 **Waveform Editor** 中（不是 Multitrack）
3. 观察频谱图：应该看到自然的混合，不是完全分离的频率

### 第 2 步：采样噪音 (关键！)
1. 打开 **Effect > Noise Reduction > Noise Reduction**
2. 点击 **Capture Noise Print** 按钮
3. **选择采样片段**:
   - 观察波形，寻找"平坦"的区域（没有明显的心跳峰值）
   - 心跳会显示为周期性的"凸起"
   - 选择 **1-2 秒** 的纯噪音片段
   - 避免选择心跳峰值区域

**⚠️ 常见错误**:
- 采样到了心跳声 → 降噪器会把心跳也消除
- 采样片段太短 → 噪音特征不完整
- 采样片段太长 → 可能包含心跳

### 第 3 步：设置降噪参数

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| **Noise Reduction** | 75-90% | 降噪强度，可根据效果调整 |
| **Reduce by** | 自动 | 让 Audition 自动计算 |
| **Smoothing** | 2-3 | 平滑处理，减少伪影 |
| **Spectral Decay Rate** | 18% | 默认值 |
| **Precision Factor** | 7 | 默认值 |

### 第 4 步：预览效果
1. 勾选 **Output Noise Only** 复选框
2. 点击 **Preview** 按钮
3. **应该听到**:
   - 纯粹的"嘶嘶"声（噪音）
   - 可能有一点点被误杀的低频
   - **不应该有明显的心跳"咚咚"声**

**如果听到心跳声**:
- 说明采样时包含了心跳
- 需要重新采样，更仔细地避开心跳峰值

### 第 5 步：应用降噪
1. 取消勾选 **Output Noise Only**
2. 点击 **Apply** 按钮
3. 等待处理完成

### 第 6 步：验证结果
1. 播放处理后的音频
2. **应该听到**:
   - 清晰的"咚咚"心跳声
   - 背景噪音大幅减少
   - 心跳节奏稳定（50 BPM）
3. **频谱图**:
   - 低频 (0-200Hz) 应该有明显的心跳峰值
   - 中高频噪音应该大幅减少

## 🔧 故障排除

### 问题 1: 降噪后仍然听不到心跳
**原因**: 
- 采样时包含了心跳
- 降噪强度太高
- 采样片段不够纯净

**解决方案**:
1. 撤销操作 (Ctrl+Z / Cmd+Z)
2. 重新采样，更仔细地避开心跳峰值
3. 降低 Noise Reduction 到 50-60%
4. 重试

### 问题 2: 降噪后听到很多伪影或"水下"声
**原因**:
- Smoothing 值太低
- Precision Factor 太高
- 降噪强度太高

**解决方案**:
1. 撤销操作
2. 增加 Smoothing 到 3-4
3. 降低 Precision Factor 到 5
4. 降低 Noise Reduction 到 70%
5. 重试

### 问题 3: 心跳声很弱，几乎听不到
**原因**:
- 降噪强度太高
- 采样片段包含了部分心跳
- 原始音频心跳能量太低

**解决方案**:
1. 撤销操作
2. 降低 Noise Reduction 到 60-70%
3. 重新采样
4. 如果仍然不行，可能需要重新生成音频（增加心跳能量）

### 问题 4: 降噪后仍有明显的噪音残留
**原因**:
- 降噪强度不够
- 采样片段不够准确
- 噪音能量太高

**解决方案**:
1. 撤销操作
2. 增加 Noise Reduction 到 90-95%
3. 重新采样，确保采样到纯净的噪音
4. 如果仍然不行，可能需要重新生成音频（降低噪音能量）

## 📝 技术背景

### 为什么这个设计有效？

1. **真实的频谱混合**
   - 心跳: 低频主导 (60Hz + 谐波)
   - 噪音: 宽带覆盖 (粉红噪音)
   - 降噪器可以有效区分

2. **自然的谐波结构**
   - 心跳包含 4 个谐波 (60Hz, 120Hz, 180Hz, 240Hz)
   - 增加了识别度
   - 降噪器更容易保留

3. **合理的能量比例**
   - 心跳: +3dB (1.4)
   - 噪音: -6dB (0.5)
   - 比例 3:1，平衡的混合，便于恢复

4. **粉红噪音特性**
   - 低频能量较高，高频能量较低
   - 更接近自然环境噪音
   - 降噪器可以有效建模和消除
