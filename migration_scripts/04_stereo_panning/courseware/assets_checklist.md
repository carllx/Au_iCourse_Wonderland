# 素材清单：04_立体声声像 (Stereo Panning & Imaging)

> **说明**: 本课程重点在于声像定位和立体声场宽度。

| 文件名建议 | 类型 | 描述 |
| :--- | :--- | :--- |
| `mono_vocal.wav` | 单声道人声 | 用于演示 Panning 定位 |
| `stereo_music.wav` | 立体声混音 | 用于分析左右声道分布 |
| `drum_kit_stems/` | **[Shared Reference]** | 请使用 `_shared_assets/drum_kit_stems/` (含 Kick, Snare, OH等) |
| `ambience_stereo.wav` | 立体声环境音 | 自然录制的双声道环境音 |
