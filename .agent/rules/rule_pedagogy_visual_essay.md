# Rule: Pedagogy - Visual Essay (视觉散文 / 演示流)

**Context**: Defines the teaching mode as a **Passive Video Experience** (Documentary/Essay), NOT an Interactive Workshop.

## 1. The "Visual Flow" Principle
**Definition**: The user is a **Viewer/Watcher**, not a User/Doer.
*   The video stream never stops.
*   There are no "Pause for Practice" moments.
*   All energy comes from the **Narrative** and **Visuals**, not from student interaction.

## 2. Demonstration Protocol (The "I Do" Rule)
*   ❌ **Prohibited Pattern**: "Now it's your turn. Pause the video and try..."
*   ✅ **Mandatory Pattern**: "Watch closely as **we** apply this effect..." / "Notice how the sound changes when **I** tweak this parameter..."
*   **Subjectivity**: Always use **"We" (Director & Audience together)** or **"I" (Director)**. Never put the burden of action on "You" (Student).

## 3. Cognitive Flow (Not Scaffolding)
Instead of "Scaffolding" (building student skills step-by-step), focus on **Cognitive Flow** (guiding attention):
1.  **Direct Attention**: "Look at this frequency peak." (Visual Anchor)
2.  **Explain Nuance**: "It looks innocent, but it's actually noise." (Insight)
3.  **Execute & Verify**: "We cut it. Now listen—the silence is deeper." ( gratification)

## 4. SCQA Narrative (Still Applies)
Keep the SCQA structure for introducing concepts, but the "Answer" is always demonstrated, never just assigned.
