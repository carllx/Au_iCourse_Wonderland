# 数字音频编辑课程资料架构说明

本目录下的文件已按照 **“平时实践 + 结课实训”** 的双轨教学理念进行整理。请参照以下指南使用。

## 📂 核心文件清单

### 1. 基础参考
*   **`Reference_Index_Guide.md` (索引指南)**
    *   **用途**: 速查。
    *   **内容**: 列出了教材 `数字音频编辑Audition实用教程-混响-2md.md` 的所有章节结构，并统计了原文中已有的演示步骤。备课时可用此定位知识点。
*   **`数字音频编辑Audition实用教程-混响-2md.md` (教材原文)**
    *   **用途**: 核心教材。包含所有理论讲解和基础操作。

### 2. 阶段一：平时教学 (分章实践)
*   **`Stage1_Chapter_Practices.md` (分章实践方案)**
    *   **适用时机**: 第 6.7、6.8、6.9、6.10 章的日常授课。
    *   **内容**: 针对教材中缺乏演示的章节，补充了对应的独立小案例（如“浴室vs音乐厅混响对比”、“卡拉OK伴奏制作”等）。
    *   **教学建议**: 讲完一章理论，立即进行对应的本实操演练。

### 3. 阶段二：结课实训 (综合项目)
*   **`Stage2_Capstone_Project.md` (综合实训：时空来电)**
    *   **适用时机**: 课程结束前的综合复习或期末大作业（替代原书 6.11）。
    *   **内容**: 一个完整的广播剧片段后期制作案例。
    *   **特色**: 串联了从 6.6 到 6.10 的所有核心技能（降噪、变调、特效、声场、混响），模拟真实工业流程。

## 🚀 备课工作流建议

1.  **课前**: 打开 `Reference_Index_Guide.md` 确认章节重点。
2.  **课中**: 
    *   讲解教材理论。
    *   (若为6.6章) 使用教材自带案例。
    *   (若为6.7-6.10章) 使用 `Stage1_Chapter_Practices.md` 中的补充案例进行演示。
3.  **期末**: 使用 `Stage2_Capstone_Project.md` 带领学生完成“时空来电”大作业，巩固全书知识。
